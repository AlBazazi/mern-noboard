MERN NoBoard

A full‑stack MERN application — a simple note-taking app made. This repository contains both the frontend and backend code.  

The project was initially built following this tutorial:  
- [MERN Stack Tutorial for Beginners with Deployment – 2025 ](https://www.youtube.com/watch?v=F9gB5b4jgOI)

Since then, I have expanded on the project as I learned more about web development. Improvements and ideas include adding features related to security, session management, and token-based authentication.
